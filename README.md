# 壁纸轮播

Windows 原生壁纸轮播工具，使用 C#、.NET 10 和 WinForms。

## 独立 EXE

分发文件为 `dist/standalone-win-x64/WallpaperSwitcher.exe`，内含 .NET 和 Windows Desktop 运行时及图标。只复制这一个 EXE 即可，不需要安装 .NET 或附带 DLL、JSON 文件。目标为 Intel/AMD x64 Windows 桌面电脑，不适用于 Windows 7/8 或 32 位系统。

新电脑上首次运行后，双击托盘图标选择该电脑上的图片目录并保存。图片和个人设置不嵌入 EXE。默认不开启开机自启动，需要时在「软件设置」中自行勾选。

## 使用

1. 退出旧版程序，打开 `dist/standalone-win-x64/WallpaperSwitcher.exe`。正常情况下按保存的设置在托盘自动开始轮播；如有未完成恢复或上次安全停止记录，会打开设置等待手动恢复。
2. 选择图片目录，设置顺序、时间间隔和快捷键，点击「开始轮播」。
3. 默认 `Ctrl + Alt + →` 切换下一张。
4. 默认 `Ctrl + Alt + End` 是壁纸开关：第一次暂停并恢复原壁纸，再按一次显示暂停前的图片并继续轮播。恢复播放后重新计时，随机顺序也会保留。
5. 「收起到托盘」后快捷键仍然有效，托盘菜单也能暂停、继续。
6. 「结束轮播」清除本轮播放状态并释放快捷键，之后可修改设置、重新开始。正常关闭窗口或从托盘退出会恢复原壁纸；异常停止或操作进行中退出则保留恢复记录，下次启动后手动恢复。

快捷键在开始轮播时注册，暂停期间保持注册；如果被其他程序占用，会提示更换组合。两个快捷键都可单独修改。

## 开机自启动

- 右侧「软件设置」中的「开机自启动」勾选后立即生效，在当前用户登录 Windows 后启动。取消勾选即可移除，无需管理员权限；程序不会自行开启。
- 「启动后在托盘自动轮播」控制普通双击启动的行为，勾选后立即保存。自启动使用 `--startup` 参数，在没有异常恢复记录时隐藏设置窗口并自动轮播。
- 启动时使用已经保存的目录、顺序、间隔和快捷键；不会先显示窗口再最小化。缺少目录、无法读图或快捷键被占用时，会在托盘提示，可双击托盘图标处理。
- 自启动项位于当前用户的 `Software\Microsoft\Windows\CurrentVersion\Run`，名称为 `SimpleWallpaperSwitcher`。不要移动或删除自启动指向的程序目录；移动后可重新勾选「开机自启动」更新路径。
- Windows 可能延迟运行自启动程序；这是登录后的桌面工具，不是在登录前运行的系统服务。
- 调试或首次设置时可运行 `WallpaperSwitcher.exe --settings`，直接打开设置窗口且不自动轮播。

## 图片和恢复

界面采用图片预览、播放列表和分类设置的两栏布局。左侧选择图片即可预览，右侧在「播放设置」和「软件设置」之间切换。

「播放设置 → 画面适配」提供六种模式，选择后立即保存，轮播期间立即生效：

| 模式 | 显示效果 |
| --- | --- |
| 填充 | 保持比例铺满屏幕，必要时裁剪边缘 |
| 适应 | 完整显示图片，不裁剪，必要时留黑边 |
| 拉伸 | 拉满屏幕，不留边，但可能变形 |
| 居中 | 保持原始像素尺寸，居中显示 |
| 平铺 | 原始尺寸重复铺满，适合纹理 |
| 跨越 | 一张图片跨越所有显示器 |

预览会模拟当前适配方式；跨屏预览以整个虚拟桌面的矩形范围示意，不模拟各屏幕之间的实际空隙。暂停或结束轮播会恢复原背景的适配方式和颜色。

「播放设置 → 竖图拼贴」默认开启，下方可选「自动」或「固定 2 / 3 / 4 / 5 / 6 张」。设置立即保存，下次切换生效；旧版设置默认沿用自动模式：

- 按当前播放顺序，将相邻的竖图自动组合为 2–6 张并排的拼贴，根据屏幕比例选择较少裁切的张数。图片保持比例、居中裁切，铺满画面且不留缝；原始文件不会被修改。
- 横图、单独的竖图，以及屏幕比例更适合单图的情况，仍按所选适配模式显示。不会跨过横图或跨越一轮末尾凑图，也不会改变播放顺序。
- 固定张数时优先使用指定数量的相邻竖图；遇到横图或本轮尾部不足时显示实际剩余张数，只有一张则单独显示。固定模式不会因屏幕比例改变所选张数，张数越多，单张图片可能裁切越多。
- 「下一张」和定时切换会前进一整组，暂停后继续显示原来的一组。预览中会标出拼贴张数和图片名称。
- 普通模式以主屏比例生成拼贴，跨越模式以整个虚拟桌面比例生成。支持根据照片 EXIF 方向识别竖图。

- 自动包含子目录，支持 JPG、JPEG、PNG、BMP、GIF 和 TIFF。GIF/TIFF 使用第一帧。
- 按目录路径进行自然名称排序（2 在 10 前）、修改时间排序、随机每轮不重复，或在列表上下移动自定义顺序。
- 轮播时所有显示器显示同一张图片。暂停、结束或退出时分别恢复原显示器的静态壁纸及显示方式。
- 原背景为纯色时，同时保存颜色和壁纸启用状态；恢复时清除 Windows 保存的图片路径并关闭图片显示，避免退出后缓存壁纸重新出现。支持旧版空图片路径的恢复记录。
- 原壁纸副本、设置与异常恢复记录存储在 `%LOCALAPPDATA%\SimpleWallpaperSwitcher`。
- 暂停期间若手动更换系统壁纸，再次继续轮播时会将新的系统壁纸作为恢复目标。
- 不恢复 Windows 原来的幻灯片播放模式；不支持动态视频壁纸、WebP 或 HEIC。
- 强制结束进程后无法立即恢复壁纸；下次启动保留恢复记录，停止自动轮播，等待点击「恢复原背景」。

## 桌面操作保护

- 安全停止时主按钮为可点击的「恢复并开始」，会先检查/恢复原背景，成功后启动轮播；也可单独点击「恢复原背景」。启动时不会自动尝试恢复，恢复失败也不会继续播放。旧版遗留的停止标记不再让主按钮一直禁用。
- 主窗口不直接调用桌面壁纸接口。每次操作启动同一个 EXE 的隐藏辅助进程，正常完成后退出，最多等待 8 秒；超时结束辅助进程并停止轮播。单屏避免使用此前发生阻塞的桌面 COM 服务，多屏操作也隔离在辅助进程内。
- 同时只允许一个桌面操作。连续快捷键和定时器不会积压请求；窗口不等待同步桌面调用。辅助进程加入 Windows Job，主程序异常退出时也会被终止。
- 锁屏、休眠或断开会话时暂停计时并取消尚未完成的辅助进程。解锁、唤醒或重新连接后，按之前的用户意图恢复：正在轮播则继续当前图片并重新计时；已经手动暂停则保持原背景，保留快捷键，等用户按键继续。原背景记录不会被当前轮播图片覆盖。
- 解锁和唤醒通知可能交错或重复。程序等所有会话阻塞解除，并延迟 1.5 秒检查交互桌面；未就绪时最多等待约 30 秒，此期间只读取桌面状态，不反复设置壁纸。真正的调用失败或超时仍进入安全停止，不自动重试或重启 Explorer；「恢复并开始」按钮保留供手动处理。
- 开始前先保存恢复记录，存在未完成记录时禁止覆盖。恢复必须收到辅助进程的成功结果，并核对原记录后才删除记录。纯黑恢复同时校验图片路径为空、背景颜色为黑色以及背景模式为纯色。
- 安全停止不等于已恢复背景。界面会明确要求手动恢复；关闭软件不会继续尝试可能阻塞的桌面调用。
- 这些措施限制本软件的挂起时间和重复调用，无法保证 Windows/Explorer 内部永不挂起。实际锁屏/休眠循环、多显示器和长时间运行仍需后续验证。

## 资源占用

- 开始轮播时复用同目录 30 秒内已完成的扫描，避免刚打开窗口或选完目录又扫描一次，也不会把刚预览的随机列表再次洗牌。点击「刷新列表」始终重新扫描；超过 30 秒或更换目录也会重新扫描。关闭窗口会取消目录扫描。
- 列表使用批量更新，并复用行文字字体。底部直接显示当前快捷键；播放设置明确标注随机模式，以及正在播放/暂停时哪些设置需要结束轮播后才能修改。快捷键冲突只提示修改组合，不再留下壁纸故障标记。
- 使用 Windows 静态壁纸，只有切换时生成图片，没有持续视频播放或逐帧刷新。定时器按用户设置的间隔触发，暂停时停止。
- 托盘隐藏或最小化时停止生成并释放界面预览；打开窗口才按需加载。预览最长边限制为 960 像素，快速选择会合并请求，最多同时处理一份预览。
- 拼贴逐张解码并释放源图，不将图库解码后常驻内存。尺寸元数据缓存上限为 4096 条，拼贴画布上限约 1678 万像素、最长边 8192 像素；缓存壁纸文件循环覆盖。
- 在内存中以 92% 质量压缩为 JPG，然后原子写入 `current-0.jpg` / `current-1.jpg` 两个文件，交替覆盖。Windows 静态壁纸接口需要真实文件路径，不能直接接收内存图片，系统自身也可能另行缓存壁纸，因此不能保证完全零写盘。
- 最近两组图片（包含单图）重复显示或暂停继续时直接复用文件，避免再次解码、压缩和写图；源文件大小、修改时间或拼贴屏幕尺寸变化会使缓存失效。压缩缓冲在写入完成后释放，不常驻缓存整套图库。
- 重复使用当前缓存槽时也不重写 `frame-cache.json`。可缩放的单图模式按屏幕需求生成较小 RGB 位图，最多 1678 万像素/8192 边长；居中和平铺保留原始像素，以免改变显示效果。原图解码仍然需要内存。
- 原壁纸按原始文件复制备份，不经过 JPG 压缩；纯色背景的颜色、适配方式和恢复记录仍独立保存。缓存文件保留供 Windows 读取，下次继续覆盖。升级前遗留的 BMP 文件不会被新版再次写入。
- 大尺寸原图仍会带来短暂解码内存峰值；切换间隔越短，平均 CPU 和磁盘开销越高。一般使用 60–300 秒间隔。

每次切换增加一次辅助进程启动开销，换取超时隔离；辅助进程退出后释放解码及合成内存。两份 JPG 缓存通过小型元数据文件跨进程复用，命中时不重写图片，但操作请求、结果与恢复状态仍有少量写盘。此前版本的内存采样不代表本版，暂不提供本版长期资源占用结论。

纯渲染测试（`WallpaperSwitcher.NativeChecks --check-render-resources`）中，6000×4000 渐变 JPG 适配 2560×1600 屏幕，额外 RGB 画布从 72,000,000 降到 13,102,080 字节，缓存 JPG 从 449,658 降到 97,781 字节。渲染、编码和写盘中位耗时由 167.7 ms 增至 195.2 ms：这是额外画布和磁盘输出的优化，不是 CPU 加速，也不代表整体进程内存减少同样比例。照片内容及硬件会影响结果。

## 开发与验证

安装 .NET 10 SDK 后：

```powershell
dotnet build .\WallpaperSwitcher\WallpaperSwitcher.csproj -c Release -o .\dist
dotnet run --project .\WallpaperSwitcher.Tests\WallpaperSwitcher.Tests.csproj -c Release
```

开发构建需要 .NET 10 SDK，普通 build 输出需要 .NET 10 Windows Desktop Runtime。对外分发请使用独立 EXE：

```powershell
.\tools\publish-standalone.ps1
.\tools\test-standalone.ps1
```

发布配置内嵌运行时和调试符号、压缩单文件，不裁剪 WinForms。独立运行检查将 EXE 单独复制到含空格和中文的目录，清除测试进程的 .NET 搜索路径，检查自带运行时、图标、桌面 API 读取以及辅助进程执行；不修改用户壁纸。

纯色恢复的原生检查位于 `WallpaperSwitcher.NativeChecks`。无参数只读检查桌面；`--repair-black-and-check` 会实际切换测试图片并最终将桌面设置为纯黑，仅用于明确需要修复黑色背景的场景。

`WallpaperSwitcher/Assets/logo.svg` 是可编辑的矢量 logo，`tools/build-logo.ps1` 使用对应几何图形生成 PNG 和 9 种尺寸的 ICO，无第三方图像依赖。

已通过 27 组核心逻辑及启动参数检查，包括暂停意图、会话通知顺序、恢复当前拼贴、取消切换不跳图、取消暂停后恢复纯黑，以及真正错误禁止自动重试。安全检查覆盖辅助进程超时、异常退出、30 个重叠请求不排队、会话取消与真正故障的区分、主程序死亡时清理子进程、重启后保留安全停止与恢复记录。单屏真实桌面检查覆盖六种适配模式、三图拼贴、重复暂停继续、跨辅助进程复用 JPG、纯黑背景恢复及原图字节一致的恢复。完整注销或重启后的自启动需实际登录验证。

`--verify-session <绝对报告路径>` 是显式诊断模式，报告目录必须先放置 `allow-session-tests` 标记，且开始时必须为纯黑背景、没有另一个壁纸程序实例。它使用隔离配置、真实 WinForms 消息循环和真实壁纸辅助进程，注入锁屏/解锁/休眠/唤醒通知，检查界面按钮、快捷键注册、计时器、当前播放组、恢复记录和黑色背景。不会真的锁屏或休眠，完成后恢复纯黑并退出。测试覆盖正常轮播自动恢复、手动暂停不自动恢复、通知交错重复、切换和暂停过程中被中断、初次开始被中断，以及真正错误后的手动恢复入口。

```powershell
# 故障注入只使用独立临时目录，不修改桌面
dotnet run --project .\WallpaperSwitcher.SafetyChecks -c Release -- .\dist\WallpaperSwitcher.exe
# 实际切换测试图片，并最终恢复纯黑；仅用于已授权的纯黑背景测试
dotnet run --project .\WallpaperSwitcher.SafetyChecks -c Release -- .\dist\WallpaperSwitcher.exe --desktop
```

`dotnet run --project .\WallpaperSwitcher.NativeChecks -c Release -- --benchmark-render` 可测量三张 2000×3000 JPG 合成为 2560×1600、92% 质量 JPG 并写盘的耗时（不会修改壁纸）。本机渐变测试图预热后五次的中位数约 159 毫秒，最大约 163 毫秒；文件为 113257 字节，同尺寸 BMP 为 12288054 字节。真实照片的压缩率随内容变化，JPG 是有损压缩。这不包含 Windows 应用壁纸及系统缓存的写入开销。

JPG 原生检查还验证了最近两组缓存命中、始终只有两个输出文件、无遗留临时文件、源图片更新失效，以及通过新服务实例恢复原始图片字节、颜色和适配模式。
